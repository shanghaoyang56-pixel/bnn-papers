## 已上传（10 篇）

| 文件 | 论文 | 用途 |
|---|---|---|
| hubara2016binarized.pdf | Binarized Neural Networks, NIPS 2016 | sign+STE 训练算法（第 1 节） |
| rastegari2016xnor.pdf | XNOR-Net, ECCV 2016 | BWN/XNOR 对比、XNOR+bitcount 卷积图 |
| umuroglu2017finn.pdf | FINN, FPGA 2017 | BN+sign 阈值合并、MVTU 结构 |
| bankman2019always.pdf | Bankman, JSSC 2019 | 开关电容神经元、CDAC+比较器（A 类） |
| yin2020xnorsram.pdf | XNOR-SRAM, JSSC 2020 | 单元/阵列结构、flash ADC 读出（C 类） |
| yin2020xnorrram90nm.pdf | XNOR-RRAM 90nm, TED 2020 (arXiv 1909.07514) | 差分 RRAM 单元、电压型 SA |
| pimball2018.pdf | PIMBALL, arXiv 1812.03989 | 互补列差分电流比较（B 类） |
| valavi2019chargedomain.pdf | Valavi 电荷域 64-tile, JSSC 2019 | 8T+MOM 电容单元、电荷域累加 |
